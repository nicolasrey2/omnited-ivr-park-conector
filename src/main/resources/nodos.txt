vamos con JSONPath

{
  "candidatos": [
    {
       "nombre": "veronica"
       "mascotas": []
    },
    {
                    "nombre": "fabian"
                    "mascotas": []
                },
                {
                    "nombre": "nico"
                    "mascotas": [
                        {
                            "nombre": "kiara"
                        },
                        {
                            "nombre": "india"
                        }
                    ]
                }
            ]
        }

segun este estandar:

    | JSONPath                           | Qué selecciona                                                                                   |
    | ---------------------------------- | ------------------------------------------------------------------------------------------------ |
    | $.candidatos[0].nombre             | "veronica"                                                                                       |
    | $.candidatos[*].nombre             | ["veronica", "fabian", "nico"]                                                                   |
    | $.candidatos[2].mascotas[*].nombre | ["kiara", "india"]                                                                               |
    | $..nombre                          | Todos los valores de nombre en cualquier nivel: ["veronica", "fabian", "nico", "kiara", "india"] |
